《七秩·杭电时光》——一个能走进去的校史小游戏
————————————————
作品名称	七秩·杭电时光（单文件网页游戏，双击运行）
实践主题	主题二：纪念杭州电子科技大学建校70周年
成果形式	其他类·电子程序（小游戏）
作者信息	姓名：高浩楠　　学号26320219：
	

一、先说为什么做这个
2026年，学校七十年。
翻校史的时候，最让我意外的是学校改名改得太频繁：杭州航空工业财经学校、杭州航空工业学校、浙江电机专科学校、浙江机械工业学校、杭州无线电工业管理学校、杭州无线电工业学校、杭州电子工业学院，最后才是杭州电子科技大学。中间还有三年，学校整个变成了一家工厂，叫学军机器厂，教室变车间，黑板旁边摆车床。这段我以前不知道。
本来想写一篇综述。校史写成时间线太无聊，写成一串“历经风雨、砥砺前行”又有点让人难以共情。后来想，不如让大家走一遍：站在1956年的校门口，看见的是一排平房，不是一段文字，就做成了游戏。
二、做成什么样
一句话概括：8个年代，24张校史卡片，8道题，一个结局。
玩法很简单。你被设定成2026级新生，从校史馆的一枚旧校徽回到1956年，每到一个年代就在校园里找几片发光的东西，走近按E读一张校史卡片；这一关的卡片读完了，回校门答一道题，答对才能进下一段。八关走完，是七十周年的夜晚。
有一处是我特意没做整齐的：每章的卡片数不一样。第3章只有2张，第8章有4张。因为我按史料多少来定，没有为了对齐硬凑。第3章那两张之外我确实没找到更具体的材料，与其编一条，不如少一张。
另外每张卡片底下有个“作者批注”，是我自己读到这里时的想法，比如“第一次读沿革表，还以为这是两所学校”。写完发现这种小字反而比正文有人味，就留了八处。

三、校史这部分我是怎么核的
原则只有一条：只用学校官网和公开报道，每张卡片底下标明出处。游戏里“?”按钮点开可以直接看到来源列表。
真做起来，麻烦的是难以确认。
第一个是下沙校区。沿革表里写着“2004年5月更名大学，校址：下沙、文一、东岳”，可下沙到底哪年启用的，我翻了官网、翻了几篇报道，都没有明确年份。最后卡片里我只写了“钱塘江畔的下沙校区建了起来”，不写具体年。少一个年份不会影响什么，编一个年份就是错的。
第二个是校训的措辞。校训是2015年4月才公示确定的“笃学力行 守正求新”，可2016年的六十周年公告里，这八个字还被称为“杭电精神”；现在的学校简介里，又变成“校训精神”。同一个东西，三个叫法。我最后按现行简介的说法写，把2015年公示这一条放在卡片里单独交代。
第三个是蒋葆增校长。钱江晚报写的是“杭州电子工业学院首任校长”，可沿革表里1980年才改建学院。我按报纸写，没敢自己改。
四、做得不够的地方
· 第4章的车间画得不像。锯齿屋顶和铁门都比真实的厂房差得远，我不会画。
· 第7、8章的场景有点空。真实的下沙校区比这挤得多，加食堂或者图书馆的一个角落会好一些，时间不够了。
· 配乐没做出来。想加一段钢琴，做不出来，现在只有一个很轻的电子音垫底，可以关掉。
· 第3章只有两张卡片，玩起来偏短。
· 手机上的方向键偏小，横屏玩才顺手。
五、AI 用到什么程度
课程要求里写着“不禁止使用AI，但不接受完全以AI自动生成作业”，这一条我按字面做了。
具体说：程序框架、像素画的绘制函数、部分文案的初稿，用了AI工具。史料核对、文案重写、关卡怎么排、哪个卡片放第几张、哪句要删，是我自己决定的。每一条史实我都在官网对过至少一遍，第三节里那三个“对不上”的地方，都是核对的时候发现的。
六、怎么玩、怎么交
· 双击“七秩杭电时光.html”，用 Chrome 或 Edge 打开，不用装任何东西，断网也能玩。按 F11 全屏效果最好。
· 操作：WASD 或方向键走，E 或空格互动，空格继续对话，1—4 选答案，Esc 打开菜单。
· 进度自动存在浏览器里，关掉再开还在。标题页的“章节选择”可以跳回任何已解锁的年代。
· 评阅的时候不用从头打，标题页点“章节选择”，里面有个“解锁全部（教学演示）”，一次解锁八章。
· 八关都过完会到七十周年那页，可以写一句祝福，点“生成我的七秩记忆卡”下载一张图，当作这次实践的纪念。
